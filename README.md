# RCA App
   
   Aplicação web para análise de causa raiz (RCA), permitindo registrar ocorrências, gerar relatórios e exportar em CSV com assinatura digital.
   
   ![Print do app] - tira um print do app rodando e arrasta pra cá depois
   
   ## Funcionalidades
   - Cadastro de registros RCA
   - Exportação para CSV
   - Assinatura digital
   - Interface em Streamlit
   
   ## Stack
   Python 3.11 | Streamlit | Pandas
   
   ## Como rodar
   pip install -r requirements.txt
   streamlit run app.py
